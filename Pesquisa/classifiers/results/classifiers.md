## Carregando datasets com ARRFiles.jl
O que é um arquivo ARFF
ARFF significa Attribute-Relation File Format (Formato de Arquivo de Atributo-Relação). É um formato de arquivo de texto usado principalmente para armazenar dados em machine learning, especialmente pela plataforma Weka (Waikato Environment for Knowledge Analysis).

Estrutura Básica
Um arquivo ARFF contém:

Cabeçalho - Define a relação e os atributos
Dados - As instâncias/exemplos em formato separado por vírgulas
Exemplo estrutural:
```
@relation nome_relacao
        
@attribute atributo1 NUMERIC
@attribute atributo2 {valor1, valor2, valor3}
@attribute classe {classe1, classe2}

@data
1.5, valor1, classe1
2.3, valor2, classe2
...
```
